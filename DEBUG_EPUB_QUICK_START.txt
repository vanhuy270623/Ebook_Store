LỖI 1: "ePub.js NOT loaded"
───────────────────────────────────────────────────────────
Nguyên nhân: CDN bị block

Giải pháp:
  # Download về local
  Invoke-WebRequest -Uri "https://cdn.jsdelivr.net/npm/epubjs@0.3.93/dist/epub.min.js" `
    -OutFile "C:\Projects\Ebook_Store\src\main\resources\static\libs\epub.min.js"

  # Sau đó sửa epub-viewer.html (dòng 10):
  <script th:src="@{/libs/epub.min.js}"></script>

LỖI 2: "File NOT accessible (404)"
───────────────────────────────────────────────────────────
Nguyên nhân: File không tồn tại

Kiểm tra:
  # File có tồn tại không?
  Test-Path "F:\datn_uploads\book_asset\source\khoahoc-vientuong\Chien Tranh Giua Cac The Gioi - H. G. Wells.epub"

  # Liệt kê tất cả EPUB
  Get-ChildItem -Path "F:\datn_uploads\book_asset\source" -Recurse -Filter "*.epub"

Nếu file KHÔNG tồn tại:
  → Upload file vào F:\datn_uploads\book_asset\source\
  → Đảm bảo folder structure đúng với DB

LỖI 3: "Failed to load EPUB"
───────────────────────────────────────────────────────────
Nguyên nhân: File corrupt hoặc không hợp lệ

Giải pháp:
  • Test file bằng Calibre
  • Test file bằng Adobe Digital Editions
  • Thử file EPUB khác
  • Re-download file gốc
