❌ NẾU VẪN LỖI
───────────────────────────────────────────────────────────
Lỗi 1: "ePub.js failed to load after 5000ms"
→ Download về local:
  Invoke-WebRequest -Uri "https://cdn.jsdelivr.net/npm/epubjs@0.3.93/dist/epub.min.js" `
    -OutFile "src/main/resources/static/libs/epub.min.js"

  Sửa HTML:
  <script th:src="@{/libs/epub.min.js}"></script>

Lỗi 2: "Test HEAD request status: 404"
→ File không tồn tại, check:
  • File có trong F:\datn_uploads?
  • Path trong DB đúng?
  • Spring Boot resource handler config?

Lỗi 3: "assetPath trống"
→ Controller không truyền asset vào model
