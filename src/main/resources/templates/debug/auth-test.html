Common Issues:

            
    
                
  • authInfo null: Spring Security chưa cấu hình đúng
    • 
                
  • principal is String: User chưa login (anonymous)
    • 
                
  • authorities empty: User không có roles

Template Access:

            

<!-- Check if authenticated -->
<div th:if="${#authentication != null and #authentication.authenticated}">
    <span th:text="${#authentication.principal.email}">Email</span>
</div>

<!-- Check role -->
<div sec:authorize="hasRole('ADMIN')">
    Admin only content
</div>
