📖 Cách Sử Dụng

Tool này giúp bạn debug Model attributes trong Thymeleaf:

  1. Xem tất cả attributes được add vào Model từ Controller
  2. Kiểm tra data types của từng attribute
  3. Phát hiện attributes null hoặc missing
  4. Debug các vấn đề liên quan đến data binding

Test với Parameters:

Thử các URL sau:

  • /debug/model-viewer?testParam=hello
  • /debug/model-viewer?testParam=12345
  • /debug/model-viewer (không có param)
