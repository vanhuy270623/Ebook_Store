📖 Usage Guide

Tool này hiển thị toàn bộ thông tin của HTTP request:

  • Basic Info: Method, URI, protocol, etc.
  • Headers: Tất cả HTTP headers (User-Agent, Accept, etc.)
  • Parameters: Query parameters và form data
  • Attributes: Request attributes được set trong application

Test với Parameters:

Try: /debug/request-info?param1=value1¶m2=value2
