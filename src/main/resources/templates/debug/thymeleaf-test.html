4. Object Access

✅ Direct property access

Book title: placeholder

✅ Method call

Book ID: placeholder

⚠️ UNSAFE - Null object access (sẽ lỗi nếu object null)

th:text="${nullBook.title}"
❌ Không nên làm như này - sẽ gây NullPointerException

✅ SAFE - Check null before access

th:if="${nullBook != null}" th:text="${nullBook.title}"
Has title ✓ Object is null - safe handling

✅ BEST PRACTICE - Elvis operator

th:text="${book.title ?: 'Chưa có tên'}"
